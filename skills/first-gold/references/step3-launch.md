# 第 3 步：宣发拉群

目标：写一条能打动目标用户的文案，发出去，并建一个反馈群，把第一批用户聚起来。

## 宣发公式

```
痛点故事（用自己的经历开头）
→ 所以我做了一个 ___ 来解决
→ 3 个功能点（每条一句话）
→ 带情绪的号召（为什么现在就该试试）
→ 体验链接 + 海报（产品截图 + 进群二维码）
```

## 每一部分怎么写

**1. 痛点故事**
- 用第一人称讲自己真实经历过的一个瞬间，越具体越好（时间、场景、当时的感受）
- 可以用一个让人一惊的事实或数字开头，但要注明来源或写成“有说法认为”，不要编造
- 一两句就够，目的是让目标用户觉得“这说的就是我”

**2. 我做了什么**
- 一句话说清：“所以我做了一个 ___，帮 ___ 解决 ___”
- 不讲技术细节，不堆 AI 名词

**3. 三个功能点**
- 每条写成“用户能得到什么”，而不是“产品有什么”
- 尽量带上可感知的结果（看得见的数字、省下的时间、改变的习惯）
- 如果有社交玩法（邀请朋友、排行榜、一起打卡），单独列一条，它最容易带来传播

**4. 带情绪的号召**
- 回到开头的痛点，给一个“为什么现在就该试”的理由
- 语气跟目标用户的说话方式一致：写给同龄人可以轻松一点，写给爸妈要直白一点

**5. 体验入口**
- 体验链接 + 海报，海报上一定有进群二维码
- 告诉别人下一步只做一件事：扫码进群，或者点链接体验

## 写好之后自查

- 把产品名遮住，目标用户还能看懂这是解决什么问题的吗？
- 前两行能不能让人停下来？小红书和朋友圈的折叠位置一般就在这里
- 有没有给出明确的下一步动作？
- 有没有夸大效果、编造数据或承诺收益？有就删掉

## 写文案时问用户的问题

1. 你自己最痛的那一刻是什么时候？能用一两句话讲出来吗？
2. 用户用了你的产品，最直接的变化是什么？
3. 如果只能讲 3 个功能，你选哪 3 个？
4. 你希望看到的人下一步做什么：点链接、扫码进群，还是私信你？

## 海报和截图

- 至少一张产品截图，让人一眼看懂这是什么
- 标题用痛点或结果，不用产品名（产品名放副标题）
- 一定放进群二维码或体验链接

## 拉群

- 建一个微信反馈群，群名直接写产品名 + “体验群”
- 进群后发一段欢迎语：产品是做什么的、怎么用、遇到问题直接在群里说
- 群里的每一条吐槽都是第 4 步的素材，记下来

## 发布清单

- [ ] 文案定稿
- [ ] 截图 / 海报准备好
- [ ] 反馈群建好，二维码放进海报
- [ ] 至少在 1 个渠道发布（小红书 / 朋友圈 / 社群），记录链接和日期
- [ ] 私聊 10 个最可能用的人，请他们试用并进群
